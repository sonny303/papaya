# Papaya engineering entry point

Read docs/team/README.md for company context, ownership, routing, and handoffs.
The default lead is papaya-engineer. Role prompts live in .cursor/agents/.
Use only specialists relevant to the task; do not launch all four by default.
When native named-agent discovery is unavailable, explicitly load the role prompt
into a supported delegated agent and pass the bounded task and source identity.
Never claim native registration merely because a prompt file exists.
Existing release, security, and incident procedures remain authoritative.
