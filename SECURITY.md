# Security policy

## Supported version

Security updates are applied to the current `main` branch. No prior release is
currently supported.

## Reporting a vulnerability

Use the repository's private
[security advisory form](https://github.com/sonny303/papaya/security/advisories/new)
to report a suspected vulnerability. Do not disclose vulnerability details in a
public issue, discussion, or pull request.

Include the affected page or component, reproducible steps, impact, and any
suggested mitigation. Maintainers will coordinate validation and disclosure in
the private advisory.
